# Deepzora 当前版本基线与历史兼容清理范围

本项目将当前版本作为第一个受支持版本。保留当前产品功能，删除为了读取、迁移、
调用或延续过去软件版本而存在的适配。此文件替代原来的“仅整理、未删除”清单。

## 兼容性边界

- 只使用 Deepzora 当前身份、目录、环境变量和持久化格式。
- 配置 schema 为 12；统一会话为 `deepzora.session.linear/v4`、schema 4、storage revision 3。
- Agent 当前会话采用 schema-2 DAG；原生插件清单采用 v2。
- 旧格式、旧字段和旧接口不进行导入、迁移、降级、双写或自动修复。
- 不支持的输入明确失败，保留原文件；不因读取失败创建一个看似成功的空会话。
- 不重新编号内部 schema，不删除 Git 历史、MIT 许可证、NOTICE 或作者归属。

## 清理范围

| 范围 | 已移除的历史适配 | 当前保留的契约或功能 |
| --- | --- | --- |
| 产品身份 | Reasonix/Deeper 路径、环境变量和格式标识回退 | Deepzora 独立身份与目录 |
| 配置 | 旧版本迁移、旧键解释、废弃选项、旧供应商标量与别名 | 当前模型列表、逐模型覆盖、凭据和配置编辑事务 |
| 会话 | 旧 codec、旧 schema/revision 读取与历史导入 | 当前事务日志、索引、稳定消息 ID 与会话 ID |
| 桌面接口 | 废弃 RPC、重复字段、旧工作区/会话调用入口 | 当前自动生成接口、身份与 generation 检查 |
| 权限 | `auto`/`yolo` 等旧模式、旧 plan trust 设置 | 三个当前权限预设、normal/plan 与显式审批规则 |
| 模型能力 | 供应商级旧视觉列表输入和配置回退 | 模型目录、逐模型覆盖、当前图像传输协议 |
| 插件与技能 | 插件命令和技能的历史短名称别名 | 包限定名称；项目和用户技能仍使用自身名称 |
| Agent/task | `fork_from` 旧输入、已退休构造器/选项和完成质量接口，旧 EBM/governor fork bundle 实验重放 | `continue_from`、当前子 Agent、DAG 分支与部分结果 |
| Goal | 历史研究分类、旧归档、不生效的配额元数据及 strict 开关 | 当前目标、累计使用量、用户预算、暂停与恢复 |
| 工具恢复 | 已退休的 resolve/retry 修改入口和恒定兼容字段 | 当前执行事实只读检查和副作用恢复 |
| 机器人 | 旧直配渠道适配、全局白名单和旧队列丢弃策略 | 当前连接记录、独立访问权限、会话绑定、队列与嵌入式运行时 |
| 主题与界面 | 老主题迁移、旧标题映射、状态栏升级标记、忽略参数的旧辅助函数和废弃提示 | 当前主题方向、明暗偏好、会话事件日志标题和主题包 |
| 计费 | 旧成本字段、显示货币源代码别名及重复镜像 | 当前 CostQuote、价格币种与显示币种 |
| 更新与发布 | 旧标签、旧指针别名、旧清单例外和旧安装布局 | 当前产物来源校验、签名、单调发布指针及事务恢复 |

## 不属于历史兼容的功能

当前外部 Claude/Codex/MCP 文件与协议接入、供应商 API 差异、操作系统差异，
属于互操作与平台支持。不能因为名称包含 compatibility 就删除。

当前 DAG 分支、崩溃恢复、写入锁、索引修复、隐私脱敏、归档/恢复/清理、远端
接管、机器人重启绑定和当前更新事务补偿，属于当前数据生命周期。它们需要继续验证。

完整支持边界及验证结果见[当前版本基线](current-version-baseline.md)。

## 后续维护

新功能直接建立当前契约。不要恢复旧数据迁移、双写字段、旧接口代理或无效参数。
历史兼容测试应删除或改为拒绝旧输入；验证当前功能的测试改用当前数据和接口。
发布前分别验证根 Go 模块、桌面 Go 模块、前端、会话阅读窗口及发布脚本。
